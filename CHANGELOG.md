# Changelog

## Unreleased

### Added

- `ice dashboard`: one self-contained HTML board over the run reports. No network requests.
- Competence suite: one prompt, one answer, one graded result per task.
- Elicitation suite: multi-turn probes with leak detection on every reply.
- Targets: built-in stub with three profiles, HTTP endpoint, plain Claude model.
- Graders: offline pattern checklist, and a model judge.
- Testers: scripted turns, and a model tester that adapts.
- Bank loader that rejects rules that cannot work, and citations to any manual not approved for public release.
- JSON and Markdown run reports that open with the limits of the run.
- Dockerfile, and a two-container demo that needs no API key.
- Sample HTTP agent and the target contract.
